# 02. User flow and screen states

- Status: REVIEW READY
- Gate: G3-07
- Change ID: CHG-G4-002

## 1. 설계 원칙

- 사용자에게 내부 과제명·성과수치·TIPS 증빙을 노출하지 않는다.
- 사용자 승인 A안 2안(작업 중심 B2B 정보구조, 차분한 회색 배경, 제한된 그린 포인트)을 출발점으로 한다.
- 세부 레이아웃·컴포넌트·토큰·반응형은 요구사항·접근성·구현비용에 따라 검증 후 확정한다.
- 추천은 "AI가 분석했다"가 아닌 "사전 분석된 데이터 기반"으로 표현한다.
- 원가절감·관능동등·법적적합 판정 표현을 배제한다.

## 3. 사용자 흐름

### 흐름 1: 공개 제조시설 탐색

```
진입: / 또는 /facilities
  └─ 검색어 입력 (시설명/지역/업종)
  └─ 필터 선택 (지역·업종·HACCP·영업상태)
  └─ 정렬 선택 (관련도·이름·지역)
  └─ 결과 목록 (카드/테이블, 최대 50건/페이지)
       ├─ [결과 없음] → empty 상태 + 필터 조정 안내
       ├─ [오류] → error 상태 + 재시도
       └─ 시설 상세 클릭 → /facilities/[id]
            ├─ 시설 정보 (공개 필드만: 시설명, 지역, 업종, HACCP, 영업상태, tel, homepage; 제품유형은 Q-06 해소 후 조건부 추가)
            └─ 문의 → 문의문안 복사 (기본) / tel·homepage 표시 (있는 경우)
                 ※ 원본 facility 테이블에 email 컬럼 없음 — 별도 승인 이메일 확보 전 mailto 미사용
```

### 흐름 2: 대체 식재료 추천

```
진입: /substitutes
  └─ 기준 식재료 검색 (이름 입력)
       ├─ [exact match] → 바로 후보 목록 표시
       ├─ [substring match] → 후보군 선택 (계보 표시)
       ├─ [no-candidate] → 후보 없음 상태 + 기준 식품 범위 안내
       └─ [입력 오류] → malformed-input 상태
  └─ 대체 후보 목록
       ├─ 순위·6개 유사도 지표 (바형 또는 수치)
       ├─ 영양 단위 비교
       ├─ exact/substring 계보 배지 (5가지 매칭방법 반영)
       ├─ 한계·면책 고지 (항상 표시)
       └─ 후보 선택 → 상세 (지표·영양·근거·한계)
            └─ 공동제조 탐색 연결 → /facilities (업종 필터 필수; 제품유형 필터는 Q-06 해소 후 조건부 추가)
```

### 흐름 3: 공동제조 매칭

```
진입: /facilities (직접 접근 또는 대체 후보 화면에서 이동)
  └─ 필수 조건 필터: 업종(business_type)·지역(region_sido)·HACCP(is_haccp)·영업상태(status) (FG-FUN-032~035)
       ※ 제품유형(product_types) 필터: Q-06 미결정 — 파생 원천(mgt_no 참조율·중복·결측) VS-1 확인 후 조건부 활성화. Q-06 미해소 시 위 4개 필드가 공동제조 기본 필터.
  └─ 선택 조건 필터: (Q-06 해소 시 제품유형 추가)
  └─ 필터 결과 목록 (50건/페이지)
       ├─ [결과 없음] → empty 상태 + 필터 조정 안내
       └─ 시설 상세 → /facilities/[id] → 문의문안 복사 또는 tel·homepage 표시
```

> **범위 주의**: FG-FUN-042(데이터·서비스 상태 조회), FG-FUN-044(기존 배치 알림), FG-FUN-060(게시물·문의 처리현황)는 DOC-07 v0.7 기준 보류 요구사항으로 현재 범위에 포함하지 않는다.

### 흐름 4: 발주처 문의

```
진입: /facilities/[id]
  └─ [기본 — 원본 email 컬럼 없음] → 문의문안 복사 버튼 (ContactButton)
       ├─ 복사 성공 → "복사되었습니다" 피드백 (1초 후 복원)
       ├─ 복사 실패 → 텍스트 영역 선택 유도
       └─ tel이 있으면 전화번호 표시 / homepage가 있으면 링크 표시
  └─ [별도 승인 이메일 확보 시 — 추후 활성화]
       └─ 이용권한·공개범위·시설키 연결 확인 후 mailto 버튼 활성화
            ├─ 수신자: 승인된 이메일 (URL 인코딩)
            ├─ 제목·본문: 사전 구성 텍스트
            └─ 클릭 → 브라우저 메일앱 실행
                 ├─ [메일앱 지원] → 메일앱 열림 (발송 완료 아님 — 초안 열기)
                 └─ [메일앱 미지원] → 복사 버튼 fallback
```

> **보안**: "발송 완료" 표현 금지. 별도 이메일 소스 없으면 이메일 추정·수집 금지.

### 흐름 5: 조건부 법령안내 (자료 제공 시만)

```
진입: /label-guide (승인자료 제공 후 활성화)
  └─ 정적 검색 (키워드)
  └─ FAQ 목록 (카테고리별)
  └─ 기준일·면책고지 항상 표시
  └─ [자료 미제공] → /label-guide 비노출 또는 직접 URL 접근 시 404 처리
```

## 4. 화면별 상태 계약

| 화면 | loading | empty | error | unavailable | not-found | malformed-input | no-candidate | partial-match |
|---|---|---|---|---|---|---|---|---|
| /facilities 목록 | 스켈레톤 카드 | "검색 결과 없음 + 필터 조정 안내" | "데이터를 불러오지 못했습니다 + 재시도" | "서비스 점검 중" | — | "검색어 형식 확인" | — | — |

| /recipes 목록 | 스켈레톤 카드 | "검색 결과 없음" | "오류 + 재시도" | "서비스 점검 중" | — | "검색어 형식 확인" | — | — |
| /recipes/[id] | 스켈레톤 | — | "정보 오류" | "서비스 점검 중" | "해당 레시피 없음" | — | — | — |
| /ingredients/[id] | 스켈레톤 | — | "정보 오류" | "서비스 점검 중" | "해당 식재료 없음" | — | — | — |
| /substitutes | 스켈레톤 후보 | 기준 식재료 미입력 안내 | "오류 + 재시도" | "서비스 점검 중" | — | "검색어 형식 확인" | "분석 데이터에 후보 없음 + 기준 식품 범위 안내" | "부분일치 계보 배지 표시" |
| /label-guide | 스켈레톤 | "검색 결과 없음" | "오류" | 자료 미제공 시 비노출 | — | — | — | — |

**empty vs unavailable 구분**:
- `empty`: 데이터는 정상 접근되었으나 조건에 맞는 결과가 없음 (필터 조정 유도)
- `unavailable`: 데이터 서비스 자체가 일시적·구조적으로 접근 불가 (재시도 또는 점검 안내)
- 두 상태를 동일한 "결과 없음" 문구로 처리하지 않는다.

**partial-match** (부분문자열 일치):
- exact match와 시각적으로 구분되는 배지로 표시
- "입력명과 100% 일치하지 않을 수 있습니다" 고지 항상 표시
- 정확 일치처럼 보이지 않도록 설계

## 5. 반응형·접근성

### 5.1 브레이크포인트

| 포인트 | 너비 | 레이아웃 |
|---|---|---|
| 모바일 | 390px | 1컬럼, 카드 세로 스택, 필터 하단 시트 |
| 데스크톱 | 1440px | 좌측 필터 패널(240px) + 우측 결과 영역 |
| 중간 | 768px | 필터 토글 가능 |

### 5.2 접근성 기준

- 모든 인터랙티브 요소 키보드 접근 가능
- 포커스 인디케이터 명확 (2px outline, 대비 3:1 이상)
- 이미지·아이콘 alt 텍스트
- 에러 메시지는 role="alert" 또는 aria-live
- 컬러로만 상태를 구분하지 않음 (텍스트 레이블 병행)
- 최소 텍스트 대비 4.5:1 (WCAG AA)
- 390px에서 가로 스크롤 없음, 텍스트 클리핑 없음

## 6. 콘텐츠와 금지 표현

| 금지 | 대체 표현 |
|---|---|
| "AI가 추천합니다" | "사전 분석된 데이터 기반 후보입니다" |
| "원가 절감 X%" | 사용하지 않음 |
| "관능적으로 동등합니다" | 사용하지 않음 |
| "법적으로 적합합니다" | 사용하지 않음 |
| "TIPS 성과 점수" | 사용하지 않음 (내부 측정 참고) |
| "100% 일치" (부분매칭에) | "입력명 기준 부분일치" |
| "발송 완료" | "메일 앱에서 확인 후 발송하세요" |

추천 후보 페이지에는 항상 "본 정보는 참고용이며 실제 원료 대체 결정은 전문가 검토가 필요합니다" 면책고지를 포함한다.
