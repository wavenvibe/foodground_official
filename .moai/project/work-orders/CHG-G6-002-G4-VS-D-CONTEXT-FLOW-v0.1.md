# CHG-G6-002 G4 VS-D 제품화 선택맥락 연결 v0.1

## 1. 목표

VS-C에서 완성한 근거형 제조후보 기능과 기존 대체 식재료 비교를 하나의 실제 사용자 흐름으로 연결한다. 레시피에서 고른 원재료와 대체 후보가 제품화 브리프, 제조후보, 시설 근거, 문의까지 유지되어 사용자가 현재 선택과 다음 행동을 화면에서 즉시 이해할 수 있어야 한다.

## 2. 권위 기준

1. `CHG-G6-002-DOCUMENT-GATE-APPROVAL.md`
2. `docs/design/chg-g6-002-integration-gate-1/service-blueprint.md`
3. `docs/design/chg-g6-002-integration-gate-1/screen-matrix.md`
4. VS-A·VS-B·VS-C QA 증빙

## 3. 데이터 계약

- 보존 값: 시작 유형·식별자·표시명, 레시피 식별자·이름, 원재료 식별자·이름, 대체 후보 표준식품 식별자·이름, 사용자 확정 제품유형·지역·CCP·공정.
- 레시피명·식재료명·대체 후보명은 현재 공개 데이터에서 읽은 값을 전달한다.
- 레시피·식재료 이름으로 제품유형·CCP를 자동 추정하지 않는다.
- 제품유형은 직접연결 265개 프로필의 실제 유형 중 사용자가 선택한다.
- URL 컨텍스트는 화면 연결용이며 권위 데이터나 영구 저장값으로 취급하지 않는다.

## 4. 구현 범위

- 레시피 상세 → 식재료 상세 → 대체 식재료 결과의 레시피·식재료 맥락 보존
- 대체 후보 카드에서 제품화 브리프로 이동하는 1차 행동
- 브리프 → 제조후보 → 시설 근거 → 문의까지 전체 맥락 보존
- 모든 해당 화면에 6단계 제품화 진행 표시와 현재 선택 요약
- 기존 대체 식재료 카드, 정렬, 6개 유사도, 100g 영양 비교 회귀 0

## 5. 검증

- 실제 레시피·식재료·대체 후보 1건의 전체 이동 경로
- 제품유형 미선택 상태에서 자동 추정 0건
- 1440×1000·390×844에서 현재 단계·다음 행동·선택 맥락 확인
- 콘솔·페이지 오류와 가로 넘침 0건
- lint·typecheck·build·VS-B/VS-C 회귀
