## 검토 질문

- 레시피와 기존 제품의 두 시작경로가 제조요건·업체 검증으로 실제 연결되는가?
- 업체 상세에 생산제품·HACCP 인증·CCP·행정정보가 근거와 기준일로 구분되는가?
- 대체 식재료의 현재 목록형 UI·6개 지표·영양 비교가 유지되는가?
- 공동제조 후보의 일치·미충족·미확인이 설명 가능한가?
- 업체명 단순 문자열 매칭과 과거 F1 런타임 오표시를 금지했는가?
- 문의가 매칭 대신이 아니라 마지막 보조행동인가?
