- 홈, 레시피 목록·상세, 식재료 목록·상세, 대체 식재료 비교, 제조시설 후보·상세, 문의 준비의 핵심 9개 화면
- 회색 Canvas `#F1F1EE`, Slate `#31394D`, Point Green `#03C75A`
- 레시피 → 식재료 → 대체 식재료 → 제조시설 후보 → 문의 준비의 연결 흐름
- 현재 대체 식재료 목록형 비교 UI, `score_final` 정렬, 6개 유사도, 100g 영양 비교, 매칭·출처 배지, 한계고지 유지
- ST-01~08, FB-01과 5종 MatchTypeBadge 상태·배지 계약
- 데스크톱 1440×1000, 모바일 390×844 반응형 기준

## 계속 적용되는 경계

- 제품 검색·연결제품·검증 이메일·제품/공정 HACCP 적합은 데이터 감사와 별도 승인 전 미노출
- 시설 `is_haccp`는 시설 인증 보유 여부로만 표현
- 회원·저장·알림·사용자용 TIPS 성과·시험·증빙 화면 미구축
- 기존 `wavenvibe/foodground`, `foodground.vercel.app`, 기존 Supabase 쓰기 금지
- 원격 Supabase·Vercel·Git 변경은 별도 사용자 승인 전 금지

## QA 기준선

- 핵심 화면 18건 + 상태·배지 부록 2건 = Playwright 20건 PASS
- HTTP 200, 문서·body·main 가로 넘침 0, 콘솔·페이지 오류 0
- UI-GATE-2 승인으로 G4 본판 로컬 구현 착수를 허용한다. 실제 배포·UAT·최종 인수를 승인한 것은 아니다.
