# Foodground target audience input

## Primary persona

persona_name: 식품 제품화 실무자
role_or_title: 소규모 식품기업 대표, 상품기획자, 개발·구매 담당자
age_range: 특정 연령을 전제하지 않음

## Goals and motivations

primary_goal: 공동생산 또는 제품화를 위해 적합한 제조업체와 식재료·레시피 대안을 빠르게 찾고 비교한다.

secondary_goals:
  - 제품화 프로젝트의 조건과 후보를 한곳에서 관리한다.
  - 대체 레시피와 제조시설 후보의 선정근거를 확인한다.
  - 식품 표시문구의 잠재 오류를 사전에 발견한다.
  - 공동구매 참여자를 모집하고 업체에 비공개로 문의한다.

## Pain points

primary_pain: 업체·제품·식재료 정보가 흩어져 있고 검색결과가 실제 제품화 의사결정으로 연결되지 않는다.

secondary_pains:
  - 검색결과가 많아 적합한 후보를 비교하기 어렵다.
  - 추천 결과의 이유와 출처를 알기 어렵다.
  - 표시문구 검토를 반복해서 수작업으로 수행한다.
  - 업체 문의에 필요한 내용을 매번 새로 정리한다.

## Decision triggers

triggers:
  - 신제품 기획 또는 시제품 개발을 시작할 때
  - 원료 수급·원가 문제로 대체재가 필요할 때
  - 생산 가능한 제조업체를 새로 찾아야 할 때
  - 표시문구 초안을 검토해야 할 때
  - 공동구매 수요를 확인하거나 견적을 요청할 때

## Objections

objections:
  - 데이터가 최신인지 알 수 없다.
  - 추천이나 점검 결과를 신뢰할 근거가 부족하다.
  - 복잡한 시스템을 학습할 시간이 없다.
  - 문의 내용과 사업정보가 공개될까 걱정된다.

## Vocabulary

their_words:
  - 생산 가능 여부
  - 제조시설
  - OEM·ODM
  - HACCP
  - 최소주문수량
  - 원료 대체
  - 표시사항
  - 견적 문의

## Secondary persona

secondary_persona_name: 제조업체 담당자
secondary_persona_role: 영업·생산·품질 담당자
secondary_persona_goal: 적합한 제품개발 문의를 확인하고 필요한 조건을 효율적으로 소통한다.
