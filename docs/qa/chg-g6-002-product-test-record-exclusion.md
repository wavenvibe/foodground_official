- 변경 ID: `CHG-G6-002-QA-PRODUCT-TEST-001`

- 상태: 로컬 구현·검증 완료

## 현상

품목보고번호 오름차순인 공개 제품 목록 첫 페이지에 식약처 원본의 시험 레코드 3건이 노출됐다.

| 품목보고번호 | 제품명 | 제조업체명 |
|---|---|---|
| `11111111111001` | `TEST` | `식약처TEST업소` |
| `11111111112001` | `TEST(주류)` | `식약처TEST업소(주류)` |
| `11111111113001` | `TEST(첨가물)` | `식약처TEST업소(첨가물)` |

## 처리 원칙

- 원본 또는 공식 신규 Supabase 행을 삭제·수정하지 않는다.
- `TEST` 문자열 패턴으로 광범위하게 제외하지 않는다.
- 확인된 품목보고번호 3개만 서버 공개 카탈로그 경계에서 제외한다.
- 목록·자유검색·직접 상세·시설 연결제품과 해당 공개 건수에 동일 규칙을 적용한다.
- 제외 레코드 직접 상세조회는 `FG_NOT_FOUND` 404로 처리한다.

## 검증 기준

1. 기본 제품 목록에 세 식별자가 없다.
2. `식약처TEST업소` 검색 결과가 0건이다.
3. 세 직접 상세 API가 모두 404를 반환한다.
4. 정상 제품명·제조업체명 포함검색과 페이지네이션은 회귀하지 않는다.
5. 기존 `foodground`와 Supabase는 변경하지 않는다.
