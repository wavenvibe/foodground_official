| 단계 | 실제 근거 | 검증 결과 |

| 레시피 | recipes·recipe_ingredients | 청국장과 돼지고기 직접 연결 |
| 대체안 | ingredient_name_match·substitute_pairs·standard_foods | exact, 후보 10개, 기존 6개 유사도·영양 비교 유지 |
| 제조요건 | 사용자 선택 | 제품유형 자동 추정 없이 빈 선택으로 진입 |
| 제조후보 | 직접연결 company profile 265개 | 과자 46개, 경상북도·CCP-S01 전체 충족 5개 |
| 시설 근거 | facility·production_log·haccp_cert·sales_suspension | 실제 시설키로 제품·HACCP·CCP·안전정보 표시 |
| 문의 | 앞 단계 선택값 | 레시피명·원재료·대체안·제품유형·CCP 문안 반영 |

## UI 계약

- 6단계 진행표시: 시작 → 식재료 → 대체안 → 제조요건 → 제조후보·업체검증 → 문의
- 레시피명, 원재료, 대체 후보, 제품유형이 URL과 화면에서 함께 유지된다.
- 완료된 이전 단계만 되돌아갈 수 있고 값이 없는 다음 단계는 완료처럼 표시하지 않는다.
- 대체 식재료 카드·점수 정렬·6개 유사도·100g 영양 비교는 유지했다.
- 후보 카드의 1차 행동은 일반 시설목록이 아니라 제품화 브리프로 연결한다.
- 레시피·식재료·대체안 이름으로 제품유형이나 CCP를 자동 추정하지 않는다.
