## 2. 핵심흐름 URL 맥락 보존 계약

```
레시피 상세 → 식재료 상세
  /recipes/[id]  →  /ingredients/[ingId]?recipe=[id]

식재료 상세 → 대체 식재료 (recipe 보존)
  /ingredients/[id]?recipe=[id]  →  /substitutes?ingredient=[이름]&recipe=[id]

대체 식재료 후보 → 제조시설 목록 (후보별 개별 액션)
  /substitutes?ingredient=X&recipe=[id]  →  /facilities?ingredient=X&substitute=[후보]&recipe=[id]

제조시설 목록 → 제조시설 상세 (3개 맥락 param 보존)
  /facilities?ingredient=X&substitute=Y&recipe=Z
    →  /facilities/[id]?back=...&ingredient=X&substitute=Y&recipe=Z

제조시설 상세 → 문의 준비 (전체 맥락 전달)
  /facilities/[id]?ingredient=X&substitute=Y&recipe=Z
    →  /inquiry?facility=[id]&facilityName=[이름]&ingredient=X&substitute=Y&recipe=Z
```

**필터 변경 시 맥락 보존:**
- FacilityFilters 폼에 ingredient/substitute/recipe hidden input → 필터 GET submit 시 맥락 유지
- 조건 초기화 링크: `/facilities?ingredient=X&substitute=Y&recipe=Z` (필터 조건만 제거)
- 페이지네이션: `currentQuery` = filterQuery + 3개 맥락 param → 페이지 이동 시 유지

맥락은 URL query string으로만 보존. 신규 영구저장 없음.
