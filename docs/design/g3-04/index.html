G3-04 · Next.js 적용 및 공통 화면상태

Implementation decision

사용자가 멈추지 않도록
모든 상태에 다음 행동을 둡니다

A안 브랜드 적용 2안을 Next.js App Router와 Tailwind CSS v4에 그대로 연결합니다. 상태는 단순 문구가 아니라 원인, 현재 결과, 다음 행동을 함께 제공합니다.

확정: 신규 UI 라이브러리를 추가하지 않고 Server Component 우선, 필요한 입력·필터·저장만 Client Component로 구현합니다.
