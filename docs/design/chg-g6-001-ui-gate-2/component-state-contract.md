# CHG-G6-001 컴포넌트·상태 계약

## 디자인 토큰

| 용도 | 값 | 계약 |
|---|---|---|
| Canvas | `#F1F1EE` | 전체 작업 배경 |
| Slate | `#31394D` | 헤더·강한 컨텍스트 패널 |
| Point Green | `#03C75A` | 1차 행동·선택·점수 |
| Surface | `#FFFFFF` | 카드·입력 표면 |
| Ink | `#20242C` | 기본 본문 |
| Rule | `#D7DBE1` | 경계·구분선 |

## 공통 컴포넌트

| 컴포넌트 | 필수 동작 | 금지 |
|---|---|---|
| Header | 레시피·식재료·대체 식재료·제조시설 4개 메뉴, 모바일 메뉴 | 제품·저장·알림·로그인 노출 |
| ContextCard | 레시피→식재료→대체후보 선택 맥락 보존 | 근거 없는 자동추천 문구 |
| SearchFilterBar | URL query 기반 검색·필터·정렬·페이지 | 클라이언트 전건 필터 |
| DataCard/ListCard | 출처·연결상태·다음 행동을 함께 표시 | 이름만 나열 |
| MatchTypeBadge | exact/substring/fuzzy/synonym/unmatched 표시 | 비정확 매칭 숨김 |
| SubstituteCandidate | score_final DESC, 6개 지표, 100g 영양 비교 | 종합점수만 표시 |
| FacilityReason | 확인된 조건과 문의할 조건을 분리 | 제품·공정 HACCP 적합 단정 |
| ContactPanel | 문의문안 복사, 공개 전화·홈페이지 연결 | 없는 이메일 생성·자동발송 |
| StatePanel | loading/empty/error/unavailable/not-found 일관 처리 | 빈 화면·무한 로딩 |

## 반응형 계약

- 1440×1000: 최대 콘텐츠 폭 1180px, 목록 카드의 정보/행동 2열, 상세 2열.
- 390×844: 본문 좌우 16px, 1열 재배치, 주요 버튼 전체폭, 표만 내부 가로스크롤 허용.
- 문서 루트와 화면 본문에는 가로 넘침이 없어야 한다.
- 모바일에서 4개 주요 메뉴에 두 번 이내 조작으로 접근한다.

## 문구 계약

- “추천”은 정렬·후보 제시 의미이며 제조 가능·법적 적합을 뜻하지 않는다.
- “시설 HACCP 보유”와 “선택 제품·공정 적합”을 분리한다.
- 유사도 결과는 참고정보이며 배합·관능·알레르기·원가·공정 확인이 필요함을 항상 표시한다.
- 문의 단계는 거래·계약이 아니라 문안 준비와 외부 연락 연결이다.
