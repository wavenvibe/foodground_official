# CHG-G6-001 UI-GATE-2 화면 매트릭스

- 상태: UI-GATE-1 사용자 방향 승인 반영 / UI-GATE-2 상세시안 검토용
- 기준 화면: `index.html?screen={screen-id}`
- 반응형 검토: 1440×1000, 390×844
- 구현 전제: 이 문서는 시각·상호작용 계약이며 실제 앱 코드를 변경하지 않는다.

| 화면 ID | URL 시안 | 사용자 질문 | 핵심 정보 | 다음 행동 |
|---|---|---|---|---|
| SCR-001 | `?screen=home` | 어디서 무엇을 시작하는가 | 5단계 제품화 흐름, 데이터 범위 | 레시피·식재료 탐색 |
| SCR-010 | `?screen=recipes` | 원하는 레시피가 있는가 | 검색·분류·정렬·페이지, 식재료 수 | 레시피 상세 |
| SCR-011 | `?screen=recipe-detail` | 어떤 재료를 대체 검토할까 | 구성 식재료·분량·연결 상태 | 식재료 허브 |
| SCR-020 | `?screen=ingredients` | 이 재료는 분석 가능한가 | 표준식품 연결·영양·연결 레시피 | 식재료 상세 |
| SCR-021 | `?screen=ingredient-detail` | 무엇과 비교하고 어디에 쓰였나 | 100g 영양·연결 레시피·대체 분석 가능성 | 대체 식재료 찾기 |
| SCR-030 | `?screen=substitutes` | 어떤 후보가 왜 유사한가 | score_final, 6개 유사도, 100g 영양 비교, 배지·한계 | 후보로 시설 찾기 |
| SCR-040 | `?screen=facilities` | 어느 시설을 검토할까 | 선택 맥락·업종·지역·시설 HACCP·후보 근거 | 시설 상세·문의 |
| SCR-041 | `?screen=facility-detail` | 무엇이 확인됐고 무엇을 물어야 하나 | 공개정보·확인 근거·미확인 조건 | 문의문안 만들기 |
| SCR-050 | `?screen=inquiry` | 업체에 무엇을 빠짐없이 물을까 | 레시피·대체안·시설 맥락·확인항목 | 문안 복사·외부 연락 |

## 공통 상태 계약

| 상태 ID | 표현 원칙 | 사용 위치 |
|---|---|---|
| ST-01 loading | 화면 골격 유지, 결과영역 스켈레톤 | 모든 목록·상세 |
| ST-02 empty | 검색조건 요약 + 조건 초기화 | 목록·후보 |
| ST-03 error | 안전한 오류문구 + 재시도 + 추적번호 | API 연결 화면 |
| ST-04 unavailable | 데이터 미연결/외부서비스 불가를 성공처럼 표시하지 않음 | 분석·연락 |
| ST-05 not-found | 잘못된 식별자와 없는 데이터를 구분 | 상세 |
| ST-06 partial-match | exact 이외 매칭방식·신뢰도·출처를 표시 | 식재료·대체재 |
| ST-07 unmatched | 표준식품 미연결, 유사도 영역 미표시 | 대체재 |
| ST-08 context-lost | 이전 선택 맥락이 없을 때 직접 검색 경로 제공 | 시설·문의 |
| FB-01 copied | 버튼 인접 영역에 성공 피드백, 일정 시간 후 해제 | 문의·전화 복사 |

## 범위 잠금

- SCR-030의 현재 목록형 대체 식재료 UI는 유지한다.
- 시설의 `is_haccp`는 시설 인증 보유 여부로만 표현한다.
- 제품·공정 HACCP 적합, 연결 제품, 검증 이메일은 데이터 감사와 별도 승인 전 표시하지 않는다.
- 제품 검색·회원·저장·알림·공개 TIPS 성과 화면은 현재 내비게이션과 본 시안에서 제외한다.
