## 2. 조인 감사

- 308개 공동제조 프로파일의 `company_id`는 `facility.mgt_no`와 직접 일치 0건이다.
- 프로파일 업체명은 `haccp_cert.biz_name`과 정규화명 기준 308건 전체가 연결되지만, 282건은 유일·26건은 중복명이다.
- `haccp_cert.facility_mgt_no`는 269건이 실제 `facility`와 연결되며, 서로 다른 시설은 261개다.
- 프로파일 업체명+지역을 HACCP 업체명+주소와 결합하면 296건은 단일 인증행, 12건은 복수 인증행으로 남는다.
- 실제 시설키 후보 기준으로는 265개 프로파일이 단일 시설, 4개가 복수 시설, 39개가 시설 미연결이다.
- 따라서 본판은 `company_profile → haccp_cert → facility`의 명시적 맵핑표와 4건 복수·39건 미연결 해소 근거가 필요하다.
- 맵핑이 확정되지 않은 프로파일은 운영 후보에 노출하지 않고 `연결 확인 필요`로 남긴다.

## 3. 제품·안전정보 연결

- `production_log.report_no` 1,047,894건은 전부 고유하다.
- 제품 815,989건이 `facility_mgt_no`를 가지며 24,055개 시설로 연결되고, 시설키 고아는 0건이다.
- 시설키가 없는 제품 231,905건은 제품검색에는 제공할 수 있으나 특정 업체의 생산제품으로 확정 표시하지 않는다.
- `sales_suspension` 355건 중 시설키로 연결되는 행은 103건이며 고아는 0건이다. 나머지는 제품명·업체명만으로 시설의 확정 행정이력처럼 표시하지 않는다.

## 4. 모델 경계

- 기존 F1 모델은 `업체 A–업체 B` 사이의 CCP·품목 패턴을 학습한 쌍비교 모델이다.
- 레시피를 바로 입력해 시설을 추천하는 모델은 아니다.
- 실제 서비스에서는 사용자가 확정한 `대상 품목 + 필요 CCP + 지역`을 가상 타겟 프로파일로 변환하는 계약이 선행돼야 한다.
- 이 계약을 실제 308개 프로파일에 대해 재검증하기 전에는 규칙 근거만 표시하고, 과거 F1을 현재 서비스 성능으로 표시하지 않는다.
