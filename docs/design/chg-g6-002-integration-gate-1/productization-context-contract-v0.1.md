# 제품화 선택맥락 계약 v0.1

## 목적

탭이 분리되어 보이던 공개 탐색 기능을 하나의 제품화 작업 흐름으로 연결한다. 이 계약은 화면 간 선택 상태를 전달하는 계약이며 새로운 추천 모델이나 영구 저장 기능이 아니다.

## 필드

| 구분 | 필드 | 근거 | 처리 |
|---|---|---|---|
| 시작점 | `sourceType`, `sourceId`, `sourceName` | 사용자가 연 제품·레시피·식재료 | 화면에 표시하고 다음 단계로 전달 |
| 레시피 | `recipe`, `recipeName` | 공개 recipe 원본 | 식재료 선택 맥락으로 전달 |
| 원재료 | `ingredientId`, `ingredient` | 공개 recipe_ingredients·ingredients | 대체 분석 기준으로 전달 |
| 대체안 | `substituteId`, `substitute` | standard_foods·substitute_pairs 결과 | 사용자가 선택한 후보만 전달 |
| 제조요건 | `item`, `region`, `ccp`, `cooking`, `sterilize` | 사용자 확인 | 근거형 제조후보 판정에 사용 |

## 금지

- 레시피명·식재료명으로 제품유형 또는 CCP 자동 추정
- URL 값을 데이터베이스 권위값으로 간주
- 대체 후보 선택만으로 제조 가능 판정
- 과거 F1이나 임의 점수를 런타임 추천 신뢰도로 표시

## 화면 연결

`레시피/제품 → 식재료 → 대체안 → 제조요건 → 제조후보·업체검증 → 문의`

각 화면은 현재 단계와 전달된 선택을 표시한다. 값이 없는 단계는 완료된 것처럼 표시하지 않으며, 최종 제조 가능성은 업체에 직접 확인한다.
