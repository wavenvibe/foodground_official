# 통합 화면 매트릭스

| 화면 | 사용자가 보는 핵심 | 다음 행동 | 필수 데이터 |
|---|---|---|---|
| 제품화 작업보드 | 현재 선택과 6단계 진행상태 | 기존 제품 또는 레시피로 시작 | recipe·production log |
| 제품·업체 탐색 | 제품명·품목·제조업체·HACCP | 제품 또는 업체 상세 | production log·facility·haccp |
| 제품화 브리프 | 선택 레시피·대체안·품목·필요 CCP | 요구조건 확정 | recipe·ingredient·user confirmation |
| 제조시설 후보 | 품목·CCP·지역·인증 일치/미충족/미확인 | 업체 근거 상세 | company profile·haccp·facility |
| 제조시설 근거 상세 | 업체정보·생산품목·인증·CCP·안전이력 | 미확인 사항 연락 | 전체 근거 연결 |

## 항상 보이는 UI

- 현재 작업: 선택 레시피/제품, 기준 식재료, 대체후보, 대상 품목, 필요 CCP
- 진행 스테퍼: 선택 → 식재료 → 대체안 → 제조요건 → 업체검증 → 연락
- 근거 배지: `공개원본`, `인증자료`, `규칙판정`, `모델보조`, `미확인`
- 다음 행동: 현재 단계에서 정확히 하나의 1차 행동
